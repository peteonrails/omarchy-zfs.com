# omarchy-zfs.com

Landing page for [omarchy-zfs](https://github.com/peteonrails/omarchy-zfs),
served by GitHub Pages at https://omarchy-zfs.com.

Static, zero-build, no external assets. Edit `index.html`, push to `main`,
Pages deploys automatically. `llms.txt`, `sitemap.xml`, `robots.txt`, and the
JSON-LD blocks in `index.html` carry the SEO/AI-discoverability payload — keep
them in sync with the package when features change.
